# CFBL — Center for Balanced Living · UI Kit

High-fidelity homepage and service-page mock for the **parent brand** of the family.

## What this kit demonstrates

The CFBL homepage works as the **central gateway** to all three brand properties. It opens with a clinical hero, three audience pathway cards (For Clients / For Professionals / MUSA), then continues with featured therapy services, a featured psychological-evaluation block, an Institute preview, a MUSA preview, a founder section, and a contact CTA.

## How to read it
Open `index.html` in a browser. Scroll once top-to-bottom to see the full pathway. The header stays sticky; pathway cards are interactive (hover); the Institute and MUSA preview blocks deliberately re-skin to their own brand palettes inside the CFBL page — this is the cross-brand pattern that makes the homepage a true gateway.

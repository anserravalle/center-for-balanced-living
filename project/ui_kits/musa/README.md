# MUSA — UI Kit

High-fidelity mock for **the author and essayist platform of Dr. Angela (Niki) Serravalle**.

## What this kit demonstrates

MUSA is a writer's platform, not a therapist's marketing channel. The visual signature is **Bone paper ground, Walnut byline rule, Oxblood accent, Ink body, generous whitespace**. The voice is first-person essayist with a clinical mind. **No marketing CTAs.** Readers self-subscribe.

The mock shows two screens — an **essay archive / homepage** and a **single essay reading view** — switchable from the masthead nav.

## Files

| File | What it is |
|---|---|
| `index.html` | The mock — archive + single essay reading view |
| `Masthead.jsx` | MUSA masthead with wordmark and editorial nav |
| `LeadEssay.jsx` | Featured essay treatment — large display headline, oxblood accent |
| `EssayList.jsx` + `EssayRow.jsx` | Archive list — ochre rules, Walnut bylines |
| `Article.jsx` | Single-essay reading view with drop cap and pull quote |
| `BookFeature.jsx` | Product-style book block (no marketing CTAs) |
| `AuthorBio.jsx` | Author bio block — by-name, no clinical credentials at top |
| `MusaFooter.jsx` | Minimal footer with self-subscribe and links to CFBL parent |

# CFBL Institute — UI Kit

High-fidelity mock for the **clinician-facing teaching arm**: training catalog homepage and a single course detail page.

## What this kit demonstrates

The Institute site is built for licensed clinicians. The visual signature is **Cream paper field, Cormorant SC headline in Forest, single Forest button or hairline rule, Sage as primary chromatic accent**. The voice is peer-to-peer, restrained, intellectually serious — no marketing CTAs, no journey metaphors, no wellness phrasing.

The mock shows two screens in one document — a sticky tab at the top lets you toggle between **Catalog** and **Course Detail** without leaving the page.
